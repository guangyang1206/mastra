# Response caching

The canonical documentation for response caching lives at  
[/docs/agents/response-caching](/docs/agents/response-caching).

## Overview

Response caching skips the LLM call and replays a previously cached
response when an agent receives an identical request. Use it to reduce
latency and avoid paying for repeated calls.

See the [full documentation](/docs/agents/response-caching) for setup,
scoping rules, and deployment patterns.
